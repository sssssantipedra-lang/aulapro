## Novedades

- **Primera versión de venta.** La aplicación pide una clave de licencia para activarse: se consigue en aulapro.app. Quien ya tenía AulaPro antes del 10-11-2026 sigue usándola gratis, sin hacer nada.
- **Nombre unificado: AulaPro.** En la aplicación, los instaladores y la web. Tus datos y tu licencia se conservan.

## Descargas
- **AulaPro-2.23.0-instalador-windows.exe**: instalación normal, con acceso directo y actualizaciones automáticas.
- **AulaPro-2.23.0-portable-windows.exe**: se ejecuta sin instalar.
- **AulaPro-2.23.0-mac.dmg**: para Mac (Intel y Apple Silicon). En Mac las actualizaciones son manuales.
- **AulaPro-2.23.0-android.apk**: para móvil y tableta Android (versión de prueba).
- **AulaPro-2.23.0-microsoft-store.appx**: paquete para subir a Microsoft Store (no se instala directamente).

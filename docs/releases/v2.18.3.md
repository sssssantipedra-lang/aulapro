## Novedades

- **Compartir en los dos sentidos.** Una vez conectados, los cambios de cualquiera de los dos docentes se reflejan al momento en el otro: si uno crea un alumno, una clase o una nota, aparece en los dos equipos. Primero se hace el envío inicial y, a partir de ahí, se trabaja a la vez.

## Descargas
- **AulaPro-2.18.3-instalador-windows.exe**: instalación normal, con acceso directo y actualizaciones automáticas.
- **AulaPro-2.18.3-portable-windows.exe**: se ejecuta sin instalar.
- **AulaPro-2.18.3-mac.dmg**: para Mac (Intel y Apple Silicon). En Mac las actualizaciones son manuales.
- **AulaPro-2.18.3-android.apk**: para móvil y tableta Android (versión de prueba).
- **AulaPro-2.18.3-microsoft-store.appx**: paquete para subir a Microsoft Store (no se instala directamente).

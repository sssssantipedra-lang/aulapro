## Novedades

- **Tamaño de las letras.** En Configuración › Apariencia, «Tamaño de las letras»: Estándar o Grande (un 25 % más grande). Se recuerda en el dispositivo. En Windows y Mac agranda la página entera; en Android, las letras.

## Descargas
- **AulaPro-2.11.3-instalador-windows.exe**: instalación normal, con acceso directo y actualizaciones automáticas.
- **AulaPro-2.11.3-portable-windows.exe**: se ejecuta sin instalar.
- **AulaPro-2.11.3-mac.dmg**: para Mac (Intel y Apple Silicon). En Mac las actualizaciones son manuales.
- **AulaPro-2.11.3-android.apk**: para móvil y tableta Android (versión de prueba).
- **AulaPro-2.11.3-microsoft-store.appx**: paquete para subir a Microsoft Store (no se instala directamente).

## Novedades

- **Tarjetas interactivas en Recursos.** Al elegir «Tarjetas» puedes escoger entre «Recortables» (las de siempre) e «Interactivas» (nuevas): tarjetas con una imagen en una cara y texto en la otra, que se giran al tocarlas. Útiles para vocabulario, ciencias o adaptaciones de material.
  - Se crean con IA o a mano, con imágenes del catálogo o pictogramas.
  - Modo de uso a pantalla completa: se giran, se barajan y se marcan «lo sé / no lo sé» para repasar solo las falladas.
  - Se pueden imprimir en PDF, como las recortables.

## Descargas
- **AulaPro-2.18.10-instalador-windows.exe**: instalación normal, con acceso directo y actualizaciones automáticas.
- **AulaPro-2.18.10-portable-windows.exe**: se ejecuta sin instalar.
- **AulaPro-2.18.10-mac.dmg**: para Mac (Intel y Apple Silicon). En Mac las actualizaciones son manuales.
- **AulaPro-2.18.10-android.apk**: para móvil y tableta Android (versión de prueba).
- **AulaPro-2.18.10-microsoft-store.appx**: paquete para subir a Microsoft Store (no se instala directamente).

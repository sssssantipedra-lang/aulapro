## Novedades

**Descargas y actualizaciones desde aulapro.app**

- A partir de esta versión, Aula Pro busca las actualizaciones y se descarga desde **descargas.aulapro.app**, la web de Aula Pro. No tienes que hacer nada: si usas Windows, esta versión se instala sola como siempre y las siguientes llegarán desde la web.

## Descargas
- **AulaPro-1.7.1-instalador-windows.exe** — instalación normal, con acceso directo y actualizaciones automáticas.
- **AulaPro-1.7.1-portable-windows.exe** — se ejecuta sin instalar.
- **AulaPro-1.7.1-mac.dmg** — para Mac (Intel y Apple Silicon). En Mac las actualizaciones son manuales.
- **AulaPro-1.7.1-android.apk** — para móvil y tableta Android (versión de prueba).

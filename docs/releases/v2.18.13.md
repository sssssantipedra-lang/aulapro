## Novedades

- **Mis fichas, más grandes.** Las tarjetas de la biblioteca de Recursos son más anchas y altas, para que el panel de «Proyectar / Memory / Editar» quepa bien dentro de cada tarjeta y los botones se vean correctamente.

## Descargas
- **AulaPro-2.18.13-instalador-windows.exe**: instalación normal, con acceso directo y actualizaciones automáticas.
- **AulaPro-2.18.13-portable-windows.exe**: se ejecuta sin instalar.
- **AulaPro-2.18.13-mac.dmg**: para Mac (Intel y Apple Silicon). En Mac las actualizaciones son manuales.
- **AulaPro-2.18.13-android.apk**: para móvil y tableta Android (versión de prueba).
- **AulaPro-2.18.13-microsoft-store.appx**: paquete para subir a Microsoft Store (no se instala directamente).

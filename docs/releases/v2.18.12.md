## Novedades

- **Juego del memory con las tarjetas interactivas.** Desde una tarjeta interactiva, el botón «Memory» abre el clásico juego de emparejar: cada imagen con su texto. Se elige el número de parejas, se juega volteando dos casillas por turno, con marcador de parejas encontradas, intentos y tiempo, y las parejas acertadas se quedan giradas viendo el resultado.

## Descargas
- **AulaPro-2.18.12-instalador-windows.exe**: instalación normal, con acceso directo y actualizaciones automáticas.
- **AulaPro-2.18.12-portable-windows.exe**: se ejecuta sin instalar.
- **AulaPro-2.18.12-mac.dmg**: para Mac (Intel y Apple Silicon). En Mac las actualizaciones son manuales.
- **AulaPro-2.18.12-android.apk**: para móvil y tableta Android (versión de prueba).
- **AulaPro-2.18.12-microsoft-store.appx**: paquete para subir a Microsoft Store (no se instala directamente).

## Descargas
- **AulaPro-2.18.7-instalador-windows.exe**: instalación normal, con acceso directo y actualizaciones automáticas.
- **AulaPro-2.18.7-portable-windows.exe**: se ejecuta sin instalar.
- **AulaPro-2.18.7-mac.dmg**: para Mac (Intel y Apple Silicon). En Mac las actualizaciones son manuales.
- **AulaPro-2.18.7-android.apk**: para móvil y tableta Android (versión de prueba).
- **AulaPro-2.18.7-microsoft-store.appx**: paquete para subir a Microsoft Store (no se instala directamente).

## Novedades

- **Orden de las sesiones a tu gusto.** En cada clase, cada sesión tiene flechas para subirla o bajarla y un asa para arrastrarla a otro lugar de su grupo (dentro de su situación de aprendizaje, o entre las que no tienen). El orden se guarda y se respeta al volver a abrir la aplicación.

## Descargas
- **AulaPro-2.22.0-instalador-windows.exe**: instalación normal, con acceso directo y actualizaciones automáticas.
- **AulaPro-2.22.0-portable-windows.exe**: se ejecuta sin instalar.
- **AulaPro-2.22.0-mac.dmg**: para Mac (Intel y Apple Silicon). En Mac las actualizaciones son manuales.
- **AulaPro-2.22.0-android.apk**: para móvil y tableta Android (versión de prueba).
- **AulaPro-2.22.0-microsoft-store.appx**: paquete para subir a Microsoft Store (no se instala directamente).
